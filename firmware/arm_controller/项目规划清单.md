# 项目规划清单

## 当前阶段

PLAN

## 当前核心目标

将 `Robotic_Arm_Control` 开发为 RA6M5 机械臂控制板固件。控制板必须作为 RS485/ModbusRTU 从机运行，固定从站地址为 `1`，通过 I2C 控制 PCA9685，再由 PCA9685 输出舵机 PWM。

## 强制开发边界

- 始终使用中文简体交流。
- 嵌入式/MCU/固件/外设/驱动相关任务默认启用 `embedded-dev`。
- 遵守本工程 `AGENTS.md` 和 Trellis 规范。
- 每次做固件代码修改前，必须先输出方案、影响范围和验证方式，等待用户审核确认后再改。
- 未经用户确认，不修改 `D:\AAAWaterCode\Rtthread_workspace\vision_board_basic`。
- 如果协议规划需要调整，先输出变更建议和影响，不直接改双方协议。

## 系统定位

- `Robotic_Arm_Control` 是机械臂控制板从机固件工程。
- vision board 是 RS485 总线主站，负责轮询和下发命令。
- ZDT 输送电机是 RS485 总线上的另一个从站，地址为 `2`。
- Robotic_Arm_Control 不作为 Modbus 主机，不主动占用总线发送数据。
- vision board 不作为机械臂低层 PWM 控制器，只通过 ModbusRTU 给机械臂控制板下发目标、模式和命令，并读取状态。

## 统一控制架构约束

- 所有控制来源，包括 Modbus 和陶晶驰串口屏，必须进入同一套机械臂状态/命令层。
- 不允许 Modbus 模块、串口屏模块或其他任务直接抢 PCA9685。
- PCA9685 输出必须由统一舵机状态模型驱动。
- 舵机输出不得绕过 `servo_target_us` / `servo_current_us` 寄存器模型。
