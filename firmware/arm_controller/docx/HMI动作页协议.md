# HMI动作页协议

本文记录 RA6M5 机械臂控制板当前 HMI 动作页串口协议，供后续 vision board / Modbus 对接时参考。

## 基本原则

- HMI 串口协议只用于本地串口屏。
- vision board 后续不要直接复用这些 HMI 串口帧，而应通过 Modbus 写寄存器/命令，再由 RA6M5 调用同一套动作模块。
- 动作数据录制时先修改 RAM 动作槽，`加一步`、`删除最后一步`、`清空` 成功后会自动同步写入 RA6M5 Data Flash，断电重启后会自动加载。
- 第一版固定动作槽位为 `0`，含义为 `NG分拣`。
- 第一版最多保存 `20` 个关键帧。
- 每个关键帧保存完整机械臂姿态：`6路舵机目标PWM(us) + 动作时间(ms)`。

## HMI发送给RA6M5

所有帧尾均为陶晶驰串口屏标准帧尾 `FF FF FF`。

```text
A5 01 ch us_l us_h FF FF FF
```

设置单路舵机目标 PWM。`ch` 为 `0-5`，`us_l/us_h` 为小端 `us`。RA6M5 必须经过 `arm_control_set_target_us()` 限幅后再输出。

```text
A5 02 FF FF FF
```

执行当前保存的复位姿态。当前固件通过动作插补层平滑回到复位姿态，默认时间为 `1000ms`，不是瞬间跳变。

```text
A5 03 FF FF FF
```

将当前 6 路目标值保存为 RAM 复位姿态。

```text
A5 04 FF FF FF
```

查询当前关节页状态。通常放在关节页前初始化事件中发送，用于让 RA6M5 回写当前姿态到关节页控件，避免切回关节页时被写死的初始值覆盖。

```text
A5 10 duration_l duration_h FF FF FF
```

加步骤。RA6M5 保存当前 6 路舵机目标值和动作时间。`duration_l/duration_h` 为小端毫秒值。加步成功后会自动同步写入 Data Flash。

```text
A5 11 FF FF FF
```

删除最后一步。删除成功后会自动同步写入 Data Flash。

```text
A5 12 FF FF FF
```

清空当前 RAM 动作。清空成功后会同步保存“0 步动作”到 Data Flash，下次上电后仍然为空。

```text
A5 13 FF FF FF
```

播放当前 RAM 动作。

```text
A5 14 FF FF FF
```

停止播放。

```text
A5 15 FF FF FF
```

查询动作页状态。通常放在动作页前初始化事件中发送。

```text
A5 31 FF FF FF
```

进入手动页，并请求 RA6M5 回写一次手动页状态。

```text
A5 32 FF FF FF
```

离开手动页。手动页底部导航跳转到其它页面前，应先发送这一帧，再执行 `page xxx`。

```text
A5 33 FF FF FF
```

查询手动页状态。通常由手动页定时器发送，用于刷新 `X/Y/Z/俯仰/旋转/夹爪` 显示和 `速度/柔和/步进` 参数显示。

## RA6M5回写HMI

关节页状态由 RA6M5 在收到 `A5 04` 后回写到以下控件：

| 控件 | 含义 |
|---|---|
| `h0-h5` | 6 个关节滑条当前目标 PWM |
| `n0-n5` | 6 个关节当前目标 PWM 数值，单位 us |
| `n6-n10` | Base/Shldr/Elbow/Pitch/Roll 的角度显示值 |
| `n11` | Grip 夹爪开合百分比 |

注意：动作页也使用 `n0`、`n1`、`n2` 等控件名，所以关节页状态只能在 `A5 04` 明确查询时回写，不能由固件后台无条件刷新。

手动页状态由 RA6M5 在收到 `A5 31`、`A5 33` 或手动点动停止/步进完成后回写到以下控件：

| 控件 | 含义 |
|---|---|
| `n0-n5` | X/Y/Z/俯仰/旋转/夹爪当前显示值 |
| `n6` | 速度 |
| `n7` | 柔和 |
| `n8` | 步进 |

注意：动作页也使用 `n5` 作为动作时间，所以手动页状态不能由固件后台定时器无条件刷新。必须由手动页明确进入、查询或点动结束触发回写，避免从手动页切到动作页后，夹爪开合值误写到动作时间控件。

动作页状态由 RA6M5 回写到以下控件：

| 控件 | 含义 |
|---|---|
| `n0` | 动作槽位，第一版固定 `0` |
| `n1` | 已录制总步数 |
| `n2` | 当前播放步 |
| `n3` | 总步数副本，用于显示 `当前/总数` |
| `n4` | 最近操作步骤 |
| `t1` | 状态文本 |

状态文本当前使用 GB2312 字节直接发送，避免 C 源码字符集影响。

## 当前播放算法

播放不是直接跳到下一帧，而是在 5ms 调度周期内对 6 路舵机做同步三次平滑插补：

```text
s(t) = 3t^2 - 2t^3
```

效果是起步和停止更柔和。后续可以在接口不变的基础上升级为 S 曲线速度规划、加速度限制、jerk 限制、负载感知的肩肘联动、逆运动学目标生成等更高级算法。
