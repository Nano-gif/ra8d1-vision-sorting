# HMI首页与手动页布局说明

本文记录陶晶驰 3.2 寸 `320x240` 串口屏的 `首页` 和 `手动` 页布局。当前阶段目标是把四个页面骨架补齐，首页可以做状态展示，手动页先完成界面占位，后续再接入 RA6M5 的手动控制/逆运动学协议。

## 背景图

最终建议导入以下两张背景图：

```text
HMI/assets/home_page_bg_320x240_v3.png
HMI/assets/manual_page_bg_320x240_v3.png
```

固定中文标签已经画进背景图，TJC 工程里只需要放会变化的数字、文本、滑条和按钮。

底部导航按钮四页统一坐标：

| 页面 | x | y | w | h |
|---|---:|---:|---:|---:|
| 首页 | 9 | 220 | 73 | 16 |
| 手动 | 87 | 220 | 73 | 16 |
| 关节 | 165 | 220 | 73 | 16 |
| 动作 | 243 | 220 | 73 | 16 |

当前页面对应的按钮在背景图里已经高亮。真正跳页仍建议放透明/同色按钮覆盖到底部导航区域。

## 首页

首页定位：状态总览页，不直接做机械臂实时控制。

首页显示内容：

```text
机械臂控制终端
机械臂状态：状态 / 模式
通信状态：视觉端在线状态 / 错误码
动作总览：槽位 / 当前步骤 / 总步骤
当前姿态：6 路 PWM
```

首页动态控件建议：

| 控件 | 类型 | 建议坐标 x,y,w,h | 用途 |
|---|---|---|---|
| `t0` | 文本 | `50,58,33,20` | 机械臂状态，例如 `就绪`、`忙碌`、`错误` |
| `t1` | 文本 | `120,58,23,20` | 控制模式，例如 `本地`、`远程`、`回放` |
| `t2` | 文本 | `210,58,33,20` | vision board 状态，例如 `在线`、`离线` |
| `n0` | 数字 | `280,58,24,20` | 错误码 |
| `n1` | 数字 | `56,126,38,16` | 动作槽位 |
| `n2` | 数字 | `137,126,38,16` | 当前步骤 |
| `n3` | 数字 | `220,126,44,16` | 总步骤 |
| `n4` | 数字 | `32,185,37,16` | Base PWM |
| `n5` | 数字 | `80,185,37,16` | Shldr PWM |
| `n6` | 数字 | `128,185,37,16` | Elbow PWM |
| `n7` | 数字 | `176,185,37,16` | Pitch PWM |
| `n8` | 数字 | `224,185,37,16` | Roll PWM |
| `n9` | 数字 | `272,185,37,16` | Grip PWM |

首页第一阶段建议事件：

- 底部导航按钮只做跳页。
- 暂时不要做首页周期查询，因为固件目前还没有首页状态回写命令。
- 如果想放一个隐藏复位按钮，也只能发送现有 `A5 02 FF FF FF`；但当前背景图没有预留明显复位按钮，避免首页承担控制语义。

后续固件需要新增一个首页状态查询命令，例如：

```text
A5 20 FF FF FF
```

该命令还没实现，暂时不要在 HMI 里填写。

## 手动页

手动页定位：后续用于 X/Y/Z、腕姿态、夹爪的实时控制。第一阶段先完成 UI，不急着启用联动算法。

手动页显示内容：

```text
末端位移：前后X / 左右Y / 上下Z
末端姿态：俯仰 / 旋转 / 夹爪
运动参数：速度 / 平滑
控制按钮：复位 / 清零 / 保留 / 保留
```

手动页动态控件建议：

| 控件 | 类型 | 建议坐标 x,y,w,h | 用途 |
|---|---|---|---|
| `n0` | 数字 | `56,61,30,16` | X 命令值 |
| `h0` | 滑条 | `94,65,46,8` | X 方向滑条，占位 |
| `n1` | 数字 | `56,86,30,16` | Y 命令值 |
| `h1` | 滑条 | `94,90,46,8` | Y 方向滑条，占位 |
| `n2` | 数字 | `56,111,30,16` | Z 命令值 |
| `h2` | 滑条 | `94,115,46,8` | Z 方向滑条，占位 |
| `n3` | 数字 | `216,61,30,16` | 俯仰命令值 |
| `h3` | 滑条 | `254,65,46,8` | 俯仰滑条，占位 |
| `n4` | 数字 | `216,86,30,16` | 旋转命令值 |
| `h4` | 滑条 | `254,90,46,8` | 旋转滑条，占位 |
| `n5` | 数字 | `216,111,30,16` | 夹爪命令值 |
| `h5` | 滑条 | `254,115,46,8` | 夹爪滑条，占位 |
| `n6` | 数字 | `61,168,44,16` | 速度百分比 |
| `n7` | 数字 | `161,168,44,16` | 平滑强度 |
| `b0` | 按钮 | `224,164,76,24` | 复位 |
| `b1` | 按钮 | `18,190,76,17` | 清零 |
| `b2` | 按钮 | `122,190,76,17` | 保留 |
| `b3` | 按钮 | `226,190,76,17` | 保留 |

手动页第一阶段事件建议：

### 前初始化事件

只初始化屏幕显示，不向 MCU 下发控制命令：

```text
n0.val=0
n1.val=0
n2.val=0
n3.val=0
n4.val=0
n5.val=0
n6.val=50
n7.val=50
h0.val=0
h1.val=0
h2.val=0
h3.val=0
h4.val=0
h5.val=0
```

### 复位按钮 `b0` 弹起事件

可以直接使用现有复位命令：

```text
printh A5 02 FF FF FF
```

### 清零按钮 `b1` 弹起事件

只清零手动页本地滑条，不发送 MCU：

```text
h0.val=0
h1.val=0
h2.val=0
h3.val=0
h4.val=0
h5.val=0
n0.val=0
n1.val=0
n2.val=0
n3.val=0
n4.val=0
n5.val=0
```

### 滑条事件

当前阶段先不要填写发送 MCU 的事件。原因是手动页不是 6 路 PWM 直控页，而是未来的末端坐标/姿态控制页，需要 RA6M5 增加新的手动控制命令，再由 `arm_control` 做坐标映射、限幅和插补。

后续建议协议另开命令号，不复用关节页 `A5 01`：

```text
A5 30 axis value_l value_h FF FF FF
```

该协议尚未确认和实现，暂时只作为后续设计方向。

## 页面导航事件

每个页面底部导航建议统一使用以下事件：

```text
// 首页按钮
page page0

// 手动按钮
page page1

// 关节按钮
page page2

// 动作按钮
page page3
```

实际页面名按你的 TJC 工程命名为准。如果现在仍是 `page0`、`page1` 这类默认名，建议先保持默认名，等四页都稳定后再统一重命名。

## 当前边界

- 首页状态查询、手动页 X/Y/Z 联动控制还没有固件协议支持。
- 手动页第一阶段不要直接发送 `A5 01` 控制舵机，否则它会变成另一个关节页，后续逻辑会混乱。
- 真正执行舵机动作必须进入 RA6M5 的 `arm_control` / `arm_action`，不能由 HMI 页面绕过统一控制层。
